# 08. [CI/CD](../../glossary.md#ci-cd), Build and Deployment

[Standards index](../README.md) · [简体中文](../../zh-CN/04-delivery/cicd-standards.md) · [P0](../../glossary.md#priority)


**Scope and owner:** [Pipelines](../../glossary.md#pipeline), [artifacts](../../glossary.md#artifact) and environments. [CI](../../glossary.md#ci-cd) maintainers own workflow and [runner](../../glossary.md#runner) trust; the release owner owns [promotion](../../glossary.md#promotion); operators own production deployment and recovery.

## Standards

- **CIC-01 MUST** run the [required checks](../../glossary.md#gate) for [change requests](../../glossary.md#change-request) and verify changes to [protected refs](../../glossary.md#ref). Define when [CI](../../glossary.md#ci-cd) runs for [change requests](../../glossary.md#change-request), [default-branch](../../glossary.md#branch) updates, tags, schedules and downstream workflows. Avoid running duplicate checks for the same candidate on both branch and [change request](../../glossary.md#change-request) events. Include validation, testing, building, scanning, packaging, publishing, deployment and verification as applicable. Never expose publishing or production credentials to untrusted [change requests](../../glossary.md#change-request).
- **CIC-02 MUST** pin toolchains, lock dependencies and pin shared [pipeline](../../glossary.md#pipeline) templates to reviewed [refs](../../glossary.md#ref). Pin production base and [CI](../../glossary.md#ci-cd) images by [digest](../../glossary.md#digest) where feasible; document controlled updates. Build from a clean checkout, isolate trusted caches and record [source SHA](../../glossary.md#sha), [pipeline](../../glossary.md#pipeline), build inputs and output identity. A cache is not a release [artifact](../../glossary.md#artifact).
- **CIC-03 MUST** publish immutable, uniquely named outputs to an approved [registry](../../glossary.md#registry). Use repository/product names plus version or commit as human-readable labels; deploy containers by [digest](../../glossary.md#digest) and other [artifacts](../../glossary.md#artifact) by immutable version and [checksum](../../glossary.md#digest). Link scan results, [SBOM](../../glossary.md#sbom) and [provenance](../../glossary.md#provenance) per [security](../03-quality/security-standards.md). Define retention per [artifact](../../glossary.md#artifact) type; retain deployed and [rollback](../../glossary.md#rollback) versions and release evidence for at least the support/[rollback](../../glossary.md#rollback) window.
- **CIC-04 MUST** [promote](../../glossary.md#promotion) the same [artifact](../../glossary.md#artifact) identity from test through [preproduction](../../glossary.md#environment) to production. Inject per-environment configuration separately. If signing, platform or packaging constraints require a new output, give it a distinct identity, verify it and re-establish its [promotion](../../glossary.md#promotion) evidence.
- **CIC-05 MUST** protect deployment environments and restrict deploy roles and credentials per environment. Development and test may deploy automatically; production needs explicit approval or a documented, authorized automated policy with equivalent gates, auditable identity and [rollback](../../glossary.md#rollback). Serialize changes per environment and reject stale [promotions](../../glossary.md#promotion).
- **CIC-06 MUST** manage deployment inputs as reviewed [desired state](../../glossary.md#desired-state). Use one authoritative deployment path. For [manifest](../../glossary.md#manifest)-managed services, application [CI](../../glossary.md#ci-cd) hands off [artifact](../../glossary.md#artifact) identity and source evidence to the deploy repository or service; it must not mutate production hosts. Use approved [Kubernetes](../../glossary.md#kubernetes), [Compose](../../glossary.md#compose) or equivalent deployment workflows as appropriate. Set resources, readiness/[health checks](../../glossary.md#health-and-readiness) and [rollout](../../glossary.md#rollout) timeouts.
- **CIC-07 MUST** verify effective [artifact](../../glossary.md#artifact) identity, health, [smoke results](../../glossary.md#smoke-test) and metrics after [rollout](../../glossary.md#rollout). Stop [promotion](../../glossary.md#promotion) on failure; use the last known good [artifact](../../glossary.md#artifact) and compatible config/[schema](../../glossary.md#schema) or execute the documented [forward fix](../../glossary.md#roll-forward)/restore. Record the observed result, not just the deployment job status.

## Default environment profile

| Environment | Trigger and identity | Gate before moving on |
| --- | --- | --- |
| Development / [change request](../../glossary.md#change-request) preview | Optional automatic deploy of a short-lived candidate; isolated credentials and data | [Smoke](../../glossary.md#smoke-test) or review feedback; expire the preview after the [change request](../../glossary.md#change-request) closes. |
| Test | [CI](../../glossary.md#ci-cd) deploys the immutable [release candidate](../../glossary.md#release-candidate) | Integration and [contract checks](../../glossary.md#contract-test) pass for this identity. |
| [Preproduction](../../glossary.md#environment) | [Promote](../../glossary.md#promotion) the same candidate with production-like configuration and representative data | Verify [migration](../../glossary.md#migration)/[rollback](../../glossary.md#rollback) readiness and critical workflows. |
| Production | [Promote](../../glossary.md#promotion) the approved candidate through the authorized deployment path | Compare observed [digest](../../glossary.md#digest) and health against thresholds; pause or recover on failure. |

Projects may combine environments where risk permits; record which gates and isolation boundaries remain.

## Procedure: [promote](../../glossary.md#promotion) and deploy

1. Check the protected candidate's [required jobs](../../glossary.md#gate), [digest](../../glossary.md#digest)/[checksum](../../glossary.md#digest) and [provenance](../../glossary.md#provenance). Confirm the current environment version, config and [migration plan](../02-development/api-data-standards.md).
2. Update and review the [manifest](../../glossary.md#manifest) or authorized change record; obtain environment approval where required. [Promote](../../glossary.md#promotion) by [digest](../../glossary.md#digest)/[checksum](../../glossary.md#digest), run [rollout](../../glossary.md#rollout), wait for readiness and exercise critical [smoke](../../glossary.md#smoke-test) paths.
3. Compare signals against predefined health/[rollback](../../glossary.md#rollback) thresholds during the observation window. On failure pause further [promotion](../../glossary.md#promotion), notify the [on-call](../../glossary.md#on-call) through the incident process, restore compatible [desired state](../../glossary.md#desired-state) or [roll forward](../../glossary.md#roll-forward), then reverify and record the outcome.

**Evidence:** [Pipeline](../../glossary.md#pipeline), [artifact](../../glossary.md#artifact) and [digest](../../glossary.md#digest), reviewed [manifest](../../glossary.md#manifest)/approval, before/after desired and observed revisions, [smoke results](../../glossary.md#smoke-test) and recovery record. See the [enforcement matrix](../enforcement.md) and [reference patterns](../reference-patterns.md).
