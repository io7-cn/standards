# 贡献与支持

[规范目录](README.md) · [English](../en/contributing.md)

艾欧柒（杭州）智能科技有限公司产品研发团队维护本规范。问题、修订建议与变更请求通过仓库工作项系统提交；维护者在其中协调审查并指定备用审查人。这些是研发要求，不代表每个接入项目已经满足所有控制。

涉及保密安全问题时，先在工作项中仅请求私下联系渠道，不包含敏感细节；维护者提供渠道后再私下说明。公开报告不得包含凭据、私有服务标识或个人数据。

需要 Python 3.9 或更高版本，检查仅使用标准库。本仓库没有应用运行时、部署环境、必填环境变量或密钥。执行：

```sh
python .ci/check-standards.py
```

同步维护 docs/en 与 docs/zh-CN 下的对应文件，对齐规则编号与要求等级，保持术语锚点稳定，行话链接到相应解释。AGENTS.md 只保留英文；辅助工具位于 .ci。目录变更须验证相对链接与接入检查工具。

提交聚焦的[变更请求](../glossary.md#change-request)，说明原因、受影响规则、兼容性影响与验证。审查覆盖双语、示例和执行要求。发布内容只保留最终维护的指引与虚构示例，不包含工作站路径、非公开标识、临时排查或生成产物。使用方通过审查并记录新提交接入更新，规范发布不自动改变其固定版本。

本仓库文档、模板和验证工具采用 [Apache 2.0 许可证](../../LICENSE)。复制模板不会自动改变使用方项目的许可证；须保留适用的版权声明。
